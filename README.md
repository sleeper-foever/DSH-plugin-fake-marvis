# DSH-plugin-fake-marvis · Firefly Assistant

面向 DeepSeek Harness Web GUI 的独立助手对话插件。原创图标参考流萤变身器的银白装甲、金色结构和青绿翼片；展开界面采用浅色像素工作室：三个独立工位的小人按同一助手的运行、等待或错误状态改变动作。这是状态插画，不代表三个真实 Agent。不依赖 Marvis 客户端，也不是 Linux 原生桌面程序。

## 安装已构建插件

仓库包含可直接加载的 `lib/index.js` 和 `lib/client.js`，无需先在自己的电脑上编译。要求已有兼容的 DSH Web 环境；此项目不是腾讯 Marvis 官方产品。

```sh
git clone https://github.com/sleeper-foever/DSH-plugin-fake-marvis.git
cd DSH-plugin-fake-marvis
dsh plugin --profile web add "link:$(pwd)" --ignore-scripts
```

确认安装成功后，按原来的管理方式重载 DSH Web 并刷新页面。不要为了本插件启动第二个替代服务。修改源码后需重新构建；新构建覆盖仓库内的运行产物。

## 独立对话

点击变身器打开面板，选择已注册的工作区，输入第一条消息后点击「开始独立对话」。插件新建专属 DSH 会话，不复用或复制主聊天会话；创建、回复与历史读取不会主动切换主界面的选择，也不覆盖主输入框草稿。仅「打开完整会话」这一明确操作会导航到助手会话，用于审批、附件、命令和完整执行信息。

回复直接呈现在助手面板中，使用 DSH 的 Markdown 渲染器。后续消息发送到同一专属会话，切换主会话不会改变助手上下文。面板关闭／隐藏不取消已接收任务。新对话按钮要求确认，原记录仍保留在 DSH。

历史记录来自 Host 的真实会话日志。位置与显示开关使用 `dsh.firefly-assistant.v1` 浏览器存储；专属会话地址使用 `dsh.firefly.assistant.session.v1`，只存会话 ID 与工作区地址，不存消息内容。刷新后验证保存的会话身份并恢复历史；不存在、被删除或身份不匹配时明确报错，不自动改发到主会话。未发送草稿只保存在内存中，刷新会清除。

主界面的会话对象没有公开的非选中会话历史初始化接口。因此助手通过同一个 DSH API 客户端读取专属会话历史，运行中串行刷新日志，并在任务结束时获取最终结果。这不会重复调用模型，也不会启动新连接泵；回复更新可能存在约一秒的延迟。主界面选中助手会话不是开始对话的前提。

## 操作与权限

- Enter 发送，Shift + Enter 换行；输入法确认与长按 Enter 不触发重复提交。
- 拖动变身器或面板手柄调整位置，手柄支持方向键。恢复、展开与缩小窗口都会约束位置到可视区域。Firefly 区域阻止指针事件冒泡到页面鼠标特效层，避免点击变身器时出现圆形水波纹；其他页面区域保持原行为。
- 在「设置 → 通用」显示／隐藏助手或恢复默认位置。系统「减少动态效果」会停用呼吸动画。
- 快捷建议只填入草稿，不自动执行；消息提交失败保留文本，不自动重试，避免连接异常时重复执行。
- 创建采用 DSH 的默认预设、模型与权限，不复制主会话策略，不额外授予权限。只读措辞属于提示，不能替代 Host 沙箱。
- 专属会话有待处理审批／提问时会显示提示并阻止绕过交互发送新消息；打开完整会话后按 DSH 原流程处理。
- 不读取屏幕、麦克风或剪贴板，不使用隐藏系统提示，不启动独立模型后端。

## 本地开发

要求已安装依赖并构建过的 DSH checkout（本版本基于 `0.1.1-rc.2` 接口）、Node.js `^22.19.0 || >=24`、pnpm。所有项目源文件和验证脚本均在本目录中。

从本目录执行：

```sh
node scripts/link-workspace.mjs /absolute/path/to/deepseek-harness
pnpm run typecheck
pnpm run build
pnpm test
pnpm run test:bundle
```

`link:local` 只在本项目的 node_modules 中链接现有 DSH 包和测试依赖，不下载包、不修改工作区清单、锁文件或用户 profile；遇到已有但指向不同位置的依赖会拒绝覆盖。客户端构建使用 DSH 的 `__ModuleLoader__` 工厂协议，不是可以单独作为应用启动的 Vite 入口。

### 浏览器验收

保持已有 DSH Web 服务运行，执行：

```sh
pnpm run test:browser http://127.0.0.1:3080
pnpm run test:served http://127.0.0.1:3080/
```

脚本在独立的无登录浏览器上下文访问已有服务的 `?fixture` 测试模式，临时把本插件的已构建客户端加入该浏览器的启动清单，通过真实 DSH 加载器、UI 插槽及会话对象运行交互检查。测试使用官方内存会话后端，屏蔽真实 API、非 GET 请求、WebSocket 和站外请求，不调用模型，不访问你的真实会话，不修改当前用户浏览器。测试组合不加载第三方插件和需要真实设置后端的提供方首次引导。

截图和结果写入 `artifacts/`。fixture 验证覆盖客户端集成，不代表已安装到你的 profile，也不替代真实 Host 权限／持久化验收。`test:served` 则检查既有服务的正常启动清单和实际客户端下载内容是否与本地构建一致，不修改任何浏览器启动配置，也不绕过登录。

## 安装到当前 GUI（需要单独确认）

完成构建并确认要修改 Web profile 后，可使用 DSH 官方插件安装入口：

```sh
dsh plugin --profile web add /absolute/path/to/deepseek-harness/plugin-package/dsh-firefly-assistant
dsh --profile web --dump-config
```

确认配置包含 `firefly-assistant` 后，通过原有服务管理方式重新加载或重启当前 DSH Web，再刷新原来的页面。不要新启动一个替代服务来冒充当前界面。未运行构建 watcher 时，修改源文件不会自动更新客户端。

卸载：

```sh
dsh plugin --profile web remove dsh-firefly-assistant
```

重载原服务并刷新页面后，浮层、样式和监听器随插件卸载。浏览器位置偏好可以保留供重新安装使用；禁用或卸载插件不会取消已接收的 DSH 任务。

## 验证范围与限制

测试覆盖专属会话创建、主选择隔离、历史恢复与消息读取、重复提交锁、失败恢复、存储校验、清理以及真实前端 fixture 交互。浏览器内存 fixture 每次重载会重建测试数据，刷新后的「原会话不存在」场景与保留真实 Host 历史的恢复单元测试分别验证。

这不是完整 Marvis 克隆：尚无系统托盘、全局快捷键、语音、跨应用感知或自动多代理路由。面板聚焦文本对话，附件、推理与工具详情请在专属会话中查看。历史和权限仍由 DSH 管理。
